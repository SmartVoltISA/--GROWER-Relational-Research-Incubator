# Molecular Property / Periodic-System Program

## Scope

The CASMI competition identifies molecular connectivity. The incubator can use the resulting molecular graph as a starting point for a broader research program.

The phrase “grow the periodic table” is interpreted operationally as a research program over chemical space, not as a claim that the periodic table itself can be generated by the model.

## Layers

### Layer A — Element knowledge

For each element:

atomic number, symbol, isotopes, electron configuration, common oxidation states, covalent/ionic radii, electronegativity and other declared reference properties.

### Layer B — Molecular structure

atoms + bonds + charge + connectivity + optional stereochemistry.

### Layer C — Derived descriptors

mass, formula, H-bond donors/acceptors, logP-related descriptors, polar surface area, ring counts, charge, valence constraints and other reproducible descriptors.

### Layer D — Predicted properties

Each prediction must include:

property name, model version, training domain, uncertainty, units and validation domain.

### Layer E — External physical evidence

Compare predictions against independent measured/reference properties where available.

### Layer F — Controlled generation

Generate candidate structures only inside an explicitly declared feasible set.

### Layer G — Falsification

Attempt to break the candidate by:

- valence/charge violations;
- mass/formula inconsistency;
- impossible or unsupported property combinations;
- out-of-domain prediction;
- disagreement with independent measurements.

## Critical distinction

Predicted physical properties are not physical measurements.

A molecule generated by the incubator is not experimentally confirmed until an independent physical/chemical experiment supports it.

The goal is therefore:

STRUCTURE → PREDICT → COMPARE → FALSIFY → REFINE → RE-TEST

not:

GENERATE → ASSUME TRUE.
