# CASMI-E010 — Controlled Molecular-Space Growth

## Status
REGISTERED / DESIGN PHASE

## Goal
Use the Incubator to grow candidate chemical space from validated structures while preserving chemical validity and evidence provenance.

## Loop
seed structure → graph edit → validity → predicted properties → evidence check → falsifier → memory → next generation.

## Boundaries
- no self-replication;
- no authority escalation;
- no claim of physical existence from computation;
- every generated molecule is a candidate until externally supported.

## Promotion
A generated family advances only when it improves held-out prediction or yields experimentally supported new chemistry.
