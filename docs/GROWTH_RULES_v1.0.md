# Ω-GROWER Growth Rules v1.0

1. Start from relations, not an assumed answer.
2. Generate multiple candidate explanations when alternatives are possible.
3. Prefer tests that can distinguish candidates.
4. Lock hypotheses, metrics and criteria before seeing the decisive result.
5. Search for failure before claiming support.
6. Preserve null, negative and positive controls.
7. Separate observation, interpretation and conclusion.
8. Track uncertainty and environmental state for physical measurements.
9. Never silently overwrite a failed branch.
10. Do not promote because a result is elegant, useful or repeated only by the same method.
11. Assemble only compatible components whose evidence scopes are explicit.
12. Keep human veto and safety boundaries outside optimization pressure.

## Growth objective
The optimizer is not “find the most convincing answer”. The objective is:

`maximize useful verified structure while minimizing unsupported inference`.

## Anti-bias rule
A candidate that survives only because competing candidates were never tested is `NOT_PROVEN`, not `SUPPORTED`.
