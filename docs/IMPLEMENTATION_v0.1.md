# Ω-GROWER Implementation v0.1

## Principle
Ω-GROWER is an incubator, not an oracle. It must grow candidate structures from explicit relations and preserve the distinction between observation, hypothesis, evidence, and conclusion.

## Minimal executable cycle
1. Receive human intent and constraints.
2. Register typed relation seeds.
3. Require at least two competing hypotheses and explicit nulls.
4. Lock the test plan before evaluation.
5. Run declared controls and discrimination tests.
6. Record observations with uncertainty and provenance.
7. Attempt falsification before promotion.
8. Classify: SUPPORTED / PARTIAL / NOT_PROVEN / FAIL / INVALID.
9. Archive rejected branches and evidence.
10. Permit assembly only from admissible verified components.

## Non-goals
- No claim of AGI.
- No automatic discovery of physical truth.
- No silent conversion of weights into probability, time, energy, or distance.
- No automatic write-back to protected Core.
- No self-replication or uncontrolled cloning.

## Prototype boundary
The current Python layer is deliberately small and deterministic. It is a state-and-evidence kernel; domain solvers and experimental instruments are external providers.
