# Ω — Minimal World / Organism Chain v0.1

## Status
CANDIDATE

## Purpose
This document fixes the research chain for constructing a minimal digital world and observing whether increasing relational complexity produces qualitatively new forms of organization.

This is an experimental hypothesis, not a claim that digital life will necessarily emerge.

## Central hypothesis
A system does not become an organized whole merely by increasing the number of agents. Qualitative organization may arise when differences, boundaries, resources, information, memory, state, impulse, inertia, choice, action and feedback form a sufficiently coupled dynamic graph.

## Fundamental principle
`difference → boundary → relation → interaction → constraint → tension/competition/cooperation → feedback → stability/change → organization`

Extreme states are not discarded. They are required as probes for locating boundaries and transitions between regimes.

## System layers

### L0 — World
- space
- time
- resource/energy budget
- environmental fields or events
- external constraints

### L1 — Minimal unit
- boundary
- identity
- internal state
- resource stock
- perception/differentiation
- information input
- memory
- impulse
- inertia
- action
- feedback
- persistence/self-maintenance

### L2 — Relations
- typed connections
- connection weight
- exchange
- resource competition
- cooperation
- conflict
- information transfer
- memory coupling
- connection formation/removal

### L3 — Choice
Choice emerges from competing possible transitions rather than being assumed as a magical primitive.
Candidate actions are evaluated against:
- current state
- resource availability
- memory
- impulse
- inertia
- information
- boundary constraints
- expected consequences

### L4 — Collective organization
Observe for:
- persistent clusters
- specialization
- division of function
- collective memory
- resource routing
- stable attractors
- collective decision patterns
- robustness after individual loss
- new properties not present in isolated units

### L5 — Higher organization
Only if evidence supports it, allow composition of lower-level structures into higher-level units:
`unit → group → functional cluster → organ-like structure → organism-like structure`

No level is assumed to exist before measurement.

## The complete dynamic chain
`WORLD → BOUNDARY → DIFFERENCE → INFORMATION → STATE → RESOURCE → NEED/DEFICIT → IMPULSE → INERTIA/RESISTANCE → CANDIDATE ACTIONS → CHOICE → ACTION → CONSEQUENCE → FEEDBACK → MEMORY → ADAPTATION → RELATION CHANGE → NEW STATE`

The cycle repeats through time. Growth changes not only node count but the structure and weight of relations; therefore graph complexity and state-space complexity must both be measured.

## Two possible growth directions

### Instrument direction
The system is optimized for a declared external objective such as ROI, throughput or task completion. Complexity is added only when it improves the objective.

### Organism direction
The system is allowed to develop additional organization when new relations, feedback loops, resource constraints and memory produce persistent collective properties.

These are alternative experimental objectives, not competing moral judgments.

## Architecture families to compare

### SWARM
High redundancy; individual units may be replaceable; collective function dominates.

### INDIVIDUAL ORGANISM
A coherent individual maintains its own boundary, state and resource economy.

### MULTI-LEVEL ORGANISM
Individual autonomy coexists with higher-level structures; resources and goals can conflict across levels.

The experiment must not assume that one architecture is universally superior.

## Graph growth principle
Adding nodes is not sufficient evidence of increasing organization.

Measure at minimum:
- node count N
- edge count E
- mean degree
- weight distribution
- connected components
- giant component fraction
- clustering
- path length
- persistence of relations
- modularity/specialization indicators where appropriate
- resource flow concentration
- state-space occupancy
- survival/persistence

A qualitative transition is only claimed when a new measurable behavior appears that is absent or substantially weaker in the appropriate control.

## Minimal controls

### C0 — Random baseline
Agents and relations without adaptive coupling.

### C1 — No memory
All other rules held constant; remove persistent historical state.

### C2 — No feedback
Actions do not alter future decision state.

### C3 — No resource constraint
Resource is effectively unlimited.

### C4 — Full minimal system
Boundary + resource + state + information + memory + impulse + inertia + choice + action + feedback + adaptive relations.

Controls are required to distinguish true emergence from complexity caused merely by more computation or more nodes.

## Extreme tests
For each major variable, test both sides of the operating range.

Examples:
- resource abundance ↔ resource scarcity
- weak boundary ↔ rigid boundary
- low memory ↔ high memory
- low inertia ↔ high inertia
- weak coupling ↔ strong coupling
- isolated units ↔ dense graph
- low conflict ↔ high conflict

The purpose is to locate regime changes and boundaries, not to force a desired result.

## Falsification targets
The hypothesis is weakened or rejected if:
1. increasing relational complexity produces no qualitative organization beyond controls;
2. apparent organization disappears under small perturbations;
3. effects are fully explained by trivial scaling or parameter artifacts;
4. no reproducible transition is found;
5. collective properties can be predicted completely from independent unit behavior without relational effects.

## Evidence rule
Every claimed transition must carry:
- exact parameter set;
- random seed(s);
- control configuration;
- run duration;
- metrics;
- raw result or reproducible artifact;
- uncertainty/tolerance;
- interpretation;
- alternative explanation;
- status.

`SUPPORTED` means supported within the declared domain and protocol. It does not mean universal truth.

## Promotion chain
`idea → anchor → formal hypothesis → preregistration → implementation → control → experiment → falsification → result → replication → promotion/archive`

## Safety / boundary
The experimental world is a sandbox. It must not write into canonical SPACE Core, alter Guardian authority, self-replicate outside declared experimental bounds, or redefine its own evaluation criteria.

## Next experimental question
What is the smallest set of primitives and relations that produces a persistent system-level property that cannot be observed in the corresponding decomposed controls?

## Non-goals
- proving consciousness;
- proving biological life;
- proving AGI;
- assuming human morality at the minimal level;
- assuming a predetermined architecture;
- optimizing for impressive demonstrations instead of reproducible evidence.
