# Security

## Scope

Ω-GROWER is a research incubator. Public repository code must not acquire authority over protected SPACE Core, Guardian, identity, credentials, or external systems merely through research outputs.

## Safety boundary

- Research candidates are not execution authority.
- Evidence is not authority.
- Promotion is not self-authorized.
- Protected boundary changes require external OperatorAuthority.
- Canonical SPACE must not be mutated by GROWER.
- No self-replication, uncontrolled cloning, credential handling, or unauthorized external action.

## Reporting

For a suspected security issue, preserve the evidence and repository history. Do not use this repository to test unrelated systems or targets without explicit authorization.

## Verification

Security-relevant changes should have a regression test and should pass the repository verification workflow before being treated as verified.
